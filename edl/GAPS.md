## FIXED RULESに関わるリスク

- RULE 2（主役は海、場所 → 空気 → 料理）：サイネージのFOOD × OCEAN（14〜22秒、料理＋水平線とフォークのスロー）を組める横の料理素材が1本もない。縦の料理を16:9に切ると、海か皿のどちらかが消える。今のままでは、サイネージの14〜22秒は「海のない料理」か「料理のない海」になる。
- RULE 2の「空気」の段階が抜けている：窓いっぱいの海（A3）、店内ワイドと窓際の空席（C1／C2）、窓の外を眺める後ろ姿（F3）、ドリンクや手元がない。海の景色からいきなりパスタへ飛ぶ構成になりやすい。料理のカット（パスタだけで動画10本と写真2枚）が体験のカットより多く、このまま組むとグルメ動画に寄る。
- サイネージのEND（夕方の海＋店名・場所）とIG30の「夕方・波・空間」：夕方の素材が1本もない（撮影は12:42〜14:32のみ）。昼の海で代用すると、構成表どおりのラストとループが作れず、ラストのSLOWな余韻も弱くなる。
- IG15のFOOD #2（ケーキ、フォークを入れる瞬間のスロー）とIG30のケーキパート：ケーキの皿のカットがゼロ。ショーケース（IMG_9651〜9653）で埋めると、値札とガラスの映り込みでメニュー紹介に見え、RULE 1（広告っぽく見せない）に反する。代用はできない。
- PLACE（サイネージ8〜14秒、IG15 1.5〜3.5秒）：窓越しの海は細い帯でしか映っていない（IMG_9674、IMG_9673）。IMG_9636は下半分が駐車場とバイク。離れて数秒だけ見るサイネージでは「店の中から海が見える」ことが伝わらない恐れがある。
- 音のルール（BGMだけで仕上げない）：単独で録った現地音がない。動画の音声は波音が小さく短い（浜のカットで−40dB前後、10秒前後）ので、IG30とIG15がほぼBGMだけの仕上がりになりかねない。
- RULE 5（MAZE WINDを海や空間と重ねて自然に浮かび上がらせる）：「MAZE WIND」と読める実物の文字は、入口マットの約1秒だけ。店内外の表記も「MAZE」「seaside MAZE」「MAZE RETREAT」と揺れていて、正式な表記とロゴデータをお店に確認するまで、End Cardとサイネージ右下の常時表示を確定できない。
- RULE 1（広告っぽく見せない）：外観のカットはどれも1階のローソンとMACHI caféの看板が目立つ。そのまま使うとコンビニの広告に見えるので、今の外観は切妻部分の切り出し以外では使えない。
- RULE 4（冒頭だけは強いフック）は縦なら成立する：IMG_9662 2.1〜3.6秒（5xで波が崩れる瞬間）。ただし手持ちで1.3〜1.5°傾いていて、回転補正と約5%の拡大が前提。横で同じ強さの5x固定はなく（IMG_9659は海だけの区間が約3.8秒で、スタビライズが必要）、サイネージの冒頭の海は2xのIMG_9658（空がやや霞む）が軸になる。
- 色（HDR→SDRの管理）：38本すべてがHDR（HLG／Dolby Vision）で、全カットにSDRへの変換が必要。晴れた空の階調と海の青をカットごとに揃える手間があり、揃わないと「海の青が主役、Natural／Clean」の色がばらつく。

### 必須：A6 夕方の水平線（横・縦）

- **なぜ必要か**：サイネージのEND（22〜30秒）は「夕方の海＋店名・場所」で、そこから冒頭の昼の海へループする構成。IG30にも「夕方・波・空間」のパートがある。今回の素材は12:42〜14:32の真昼だけで、夕方のカットが1本もない。このままではサイネージのラストとループ、IG30の終盤（ラストSLOW）が構成表どおりに組めない。
- **追加で撮るべきショット**：浜から1xで、水平線を画面の上から約40%に置いた固定を20秒以上。横（サイネージ用）と縦（IG30用）の両方。日没の約60分前から日没後15分まで、15分おきに同じ構図で撮って空の色の変化を押さえる。斜めの光で金色に光る波を入れた構図と、岬のシルエットを入れた構図も1本ずつ。
- **iPhone 16 Pro Maxでの撮り方**：1x、4K/60fps、HDRビデオはオフ。三脚で固定し、横の1台と縦の1台（同行者のiPhone）を並べて同時に回す。グリッドと「水平」（設定 → カメラ）をオン。水平線より少し上の空を長押ししてAE/AFロックし、太陽マークを−0.7〜−1.0まで下げて夕焼けの色を残す。ホワイトバランスのロックはオンのまま（夕方の暖かさを自動補正で消さない）。9月下旬の高知の日没は18時前後なので、17時〜18時15分は浜にいる（撮影日の日没時刻は前日に確認）。海は南向きで、太陽は海岸線の西側（右手の岬の方向と思われる）に沈むので、現地で方角を確かめ、太陽を直接入れるより、染まる空と光る波を狙う。天気が崩れた場合に備えて、お店に夕日の映像・写真（STORE_ASSETS C2）もお願いしておく。

### 必須：現地音の単独収録（波・風・店内・食器）

- **なぜ必要か**：音のルール「BGMだけで仕上げない。波・風・食器などの現地音で、その場にいる感覚を作る」。IG30とIG15は現地音＋BGMの設計だが、単独で録った音が1本もない。動画の音声は、浜のカットが10秒前後で−40dB前後と小さく、店内のカットは短いうえに操作音などが混じる可能性がある。このままではIGの2本がほぼBGMだけになる。
