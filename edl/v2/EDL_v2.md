## 2026-10-17 文字の被りの修正
4本を全コマで確かめ、文字が看板・値札・建物の文字・地図の線・Reels の UI と重なる所を直した。構成・秒数・コピーは変えていない。
- **文字の後ろに板**：フロア名（1F・2F・3F）は、左端から文字の右まで、縁をぼかしたすりガラスの帯を敷く（背景をぼかし、明るい所ほど暗くする）。フロアガイドの名前は小さなすりガラスの板、地図の出典は細い暗い帯。板は文字と一緒に出て消える
- **IG の UI**：文字はすべて Reels の上14%・下35%・左右6%の外。フロア名を少し上げ、END は看板を小さくして上に寄せ、文字を下の暗い壁に置いた（窓の灯りは壁の暗さへ溶かす）
- **冒頭**：IG は水平線より下の沖の海、サイネージは橋のない右下の川面へ
- **地図**：地名を田畑・河原・道筋の上から外へ（土佐市は市街地の南の山林、仁淀川は下流の東の山林、桂浜は点の右下の海、高知県は県の内側）。土佐市と仁淀川は同時に出さない。画面の端（IG は UI の手前）に近づいた地名は薄くして消す。道筋は南風の名前が出る前に消し、名前はピンの輪より上に。出典は IG では UI より上に2行
- **車窓**：文字を建物の上の空へ（サイネージは画角を少し上に向けて空の帯を作る）。空の上の方を文字と一緒に少し暗くする。40秒版はタワーの避雷針が来る前に消す
- **建物（昼→夜）**：屋根より上の暗い空へ（IG は「Seaside MAZE ｜ 南風」の1行、サイネージは左上）。看板の光がせり上がる前に消す
- **1F**：地酒（仁淀川）のカットでは文字を出さない（箱の筆文字と重なるため）
- **2F**：階段（1F のロビー）では出さず、2F のカウンターのカットから
- **フロアガイド**：点はフォントの「●」をやめて図形の丸に（文字化けしていた）。名前の左右は1本のあいだ固定。サイネージの1Fの点はローソンの看板の上のひさしへ。IG の1Fは点を1Fの柱に置き、名前は UI より上に出して線でつなぐ。IG の各フロア名は、点が画面に入ってから出る
- **END（サイネージ）**：3行を左の暗い壁に左揃え（看板の「南風」と光の輪を避ける）

### 2回目の確認のあとで直したこと
- **1F の産直の連打**：帯の縁に値札・シールの文字がくっきり並び、テロップの続きに読めてしまうカットを外した（IG：乾燥とうがらし・さつまいも・直七、サイネージ：直七。どこを切り出しても値札が帯に接するもの）。トマトのシールと赤たまねぎの値札は、切り出しを横にずらして文字から離した。黄 → 橙 → 赤 → 紫 → 緑 の順はそのまま。IG は10枚（40秒版は1枚11コマ）、サイネージは12枚。IG 20秒版はローソンの入口のカットが戻った
- **地図の航空写真**：ズームの段（タイル）が1コマで切り替わって色が跳び、沖のタイルの無い所が四角いつぎはぎに見えていた。となりの段と なめらかに重ね、タイルの無い所はまわりの同じ段の写真の色で埋める
- **屋上（IG）**：帯を水平線と砂州のあいだに収め、水平線を隠さない
- **フロアガイド（IG）**：名前が画面の端で急に止まる・動き出すのをやめた（1F は中央に固定し、線だけが点について動く）。2F は点が画面に入ってからゆっくり出る。点と線の縁をなめらかに
- **フロアガイド（サイネージ）**：タワーの点を避雷針の右へ、2F の点を壁の照明の下へ
- **車窓（20秒版）**：横の流れを40秒版の前半と同じ速さにした（タワーの避雷針が文字の後ろを通らない）。ブレはコマの間を7枚重ねてなめらかに
- **建物（サイネージ）**：明かりのついた軒がせり上がる前に文字を消し終える
- **END**：最後のコマまで文字を残す（文字だけが先に消えない）

### 4回目（3回目の確認のあとで直したこと）
- **文字**：「土佐市」を写真の白い造成地から少し北へ。IG の 1F の文字は、入口ののぼり・看板が行末に並ぶので、産直の最初のカットから出す。しょうが（IG）とさつまいも（サイネージ）は切り出しを横にずらして値札を文字から離した
